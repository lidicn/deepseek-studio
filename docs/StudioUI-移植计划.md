# StudioUI 完整移植计划

> 目标：在 deepseek 网页中注入完整 UI，以豆包工作界面为蓝图，打造 StudioUI 体验。
> 技术方案：纯 DOM 注入 + CSS（与现有 tool-card-ui 同一技术栈），通过宿主 WebSocket API 获取数据。

## 界面蓝图（豆包工作）

### 整体布局
```
┌──────────┬──────────────────────────────────┬──────────┐
│ 左侧边栏  │         主聊天区（deepseek）       │ 右侧边栏  │
│          │                                  │          │
│ 导航菜单   │  对话内容                        │ 对话产物  │
│ 项目列表   │  工具卡片                        │ 后台任务  │
│          │                                  │ 任务规划  │
│ 用户+设置  │  [输入框增强栏]                  │ 技能列表  │
│          │  输入框                           │ 最近文件  │
└──────────┴──────────────────────────────────┴──────────┘
```

### 左侧边栏
- 顶部：新工作任务、定时任务、插件·技能·伙伴、云盘
- 项目分组：项目列表（可点击切换），每个项目显示名称+路径
- 底部：用户头像+名称、设置齿轮按钮

### 右侧边栏
- 对话产物：本次对话生成/修改的文件列表
- 后台任务：正在执行的工具调用/命令
- 任务规划：Agent 的任务分解（如启用）
- 技能：已启用的技能列表
- 最近文件：最近访问的文件

### 输入框增强栏
- 本地电脑开关（控制是否启用本地工具）
- 项目选择按钮（显示当前项目，点击弹出项目选择器）
- 权限模式（全部允许/每次询问）
- 技能按钮（弹出技能管理面板）
- 插件按钮（预留）

### 弹窗组件
- 设置面板：工作区、策略模式、MCP 管理、技能目录、记忆管理
- 项目选择器：项目列表、新建项目、从文件夹创建
- 技能管理：技能列表、启用/禁用、详情预览
- MCP 配置：服务器配置表单、测试连接

## 技术方案

### 注入方式
- 所有 UI 通过 `document.createElement` 动态创建，注入到 deepseek 网页 DOM
- 使用 Shadow DOM 隔离样式，避免与 deepseek 网页样式冲突
- 统一的 CSS 变量系统，匹配 deepseek 网页暗色/亮色主题

### 数据通信
- UI 组件通过 `window.__studioHost` 桥接对象调用宿主 API
- 宿主 API 走 WebSocket（已有 host-client 通道）
- 新增 UI 专用消息类型：`ui-state`、`ui-action`

### 状态管理
- 轻量级状态管理：每个 UI 组件内部维护状态，通过事件总线通信
- 全局状态：当前项目、工作区、策略模式、技能列表、MCP 服务器列表

### 样式规范
- 主色调：deepseek 蓝（#4D6BFE）
- 背景：#FFFFFF（亮色）/ #1A1A2E（暗色）
- 侧边栏宽度：240px
- 圆角：8px
- 字体：系统默认 sans-serif

## 宿主 API 扩展（UI 需要的新接口）

### 项目管理
- `project.list` — 列出所有项目
- `project.create` — 创建新项目（名称+路径）
- `project.switch` — 切换当前项目
- `project.delete` — 删除项目

### 配置管理
- `config.get` — 获取配置
- `config.set` — 设置配置
- `config.workspace.set` — 设置工作区路径
- `config.policy.set` — 设置策略模式

### UI 状态
- `ui.state` — 获取当前 UI 状态（项目、工作区、策略、技能、MCP）
- `ui.state.subscribe` — 订阅状态变更

## 实现细节

### UI-1 左侧边栏
- 固定定位在页面左侧，width: 240px
- deepseek 网页主内容区 margin-left: 240px
- 项目列表从宿主 API 获取，点击切换项目
- 设置按钮点击弹出设置面板

### UI-2 右侧边栏
- 固定定位在页面右侧，width: 280px
- 默认折叠，可通过按钮展开/收起
- 对话产物从工具记录中提取（file.write 操作的文件）
- 后台任务显示正在执行的 shell_exec/python_exec
- 技能列表从 skill.list 获取

### UI-3 输入框增强栏
- 注入到 deepseek 输入框上方
- 本地电脑开关：控制是否注入工具能力提示词
- 项目选择：显示当前项目名称，点击弹出项目选择器
- 权限模式：切换 full/auto/ask
- 技能按钮：弹出技能管理面板

### UI-4 设置面板
- 模态弹窗，居中显示
- Tab 切换：通用、工作区、策略、MCP、技能、记忆
- 通用：版本信息、日志路径、重置
- 工作区：当前工作区路径、修改按钮
- 策略：full/auto/ask 三选一
- MCP：服务器列表、添加/编辑/删除
- 技能：技能目录路径、扫描按钮
- 记忆：记忆列表、删除按钮

### UI-5 项目选择器
- 模态弹窗，居中显示
- 顶部：对话/工作 模式切换
- 项目列表：名称+路径，点击切换
- 底部：创建新项目、通过本地文件夹创建
- 搜索框：过滤项目

### UI-6 技能管理面板
- 侧边弹窗（从右侧滑入）

- 点击技能展开详情：SKILL.md 内容预览
- 底部：打开技能目录、添加技能

### UI-7 MCP 配置弹窗
- 模态弹窗
- 表单：服务器名称、传输类型（stdio/HTTP/SSE）、命令/URL、参数、环境变量
- 自定义 Headers（动态添加/删除行）
- 测试连接按钮
- 保存/取消

## 风险与应对

| 风险 | 应对 |
|------|------|
| deepseek 网页 DOM 结构变化导致注入位置失效 | 使用多个候选选择器，定期检查注入元素是否存在 |
| 样式冲突 | 使用 Shadow DOM + 唯一类名前缀（studio-ui-） |
| 性能影响（大量 DOM 操作） | 懒加载右侧边栏，虚拟滚动项目列表 |
| 移动端适配 | 小屏幕自动隐藏侧边栏，添加展开按钮 |

5. 项目选择器可新建/切换项目
6. 技能管理面板可查看/启用技能
7. MCP 配置弹窗可添加/编辑 MCP 服务器
8. 所有 UI 在亮色/暗色主题下正常显示
