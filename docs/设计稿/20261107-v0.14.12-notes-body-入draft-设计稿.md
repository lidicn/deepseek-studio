# v0.14.12 设计稿：Release 页 body 从 notes 文件补齐

## 问题
GitHub Release **页面 body 为空**（v0.14.11 与 v0.14.8 均 0 字符，两次）。应用内更新弹窗有正文（读 `latest.json` 的 `notes`，来自仓库 `docs/release-notes-<tag>.md`）；但 Release 页 body 从未被填充——用户访问 releases/tag/v0.14.11 看不到说明。

## 根因
`release.yml` 的 `Create draft release` 步（`softprops/action-gh-release@v2`）只传 `draft: true`／`files:`／`tag_name:`，**不传 `body` 或 `body_path`**。`latest.json` 的 notes 在 `Compose latest.json` 步单独组装、作为 asset 上传；Release 页 body 是另一条独立链路、从未接上。

## 修法（一行＋配套守卫调整）
`Create draft release` 步的 `with:` 块加 `body_path: docs/release-notes-${{ github.ref_name }}.md`。
- `action-gh-release@v2` 读该文件、设为 Release body；
- 文件在 tag commit 的 checkout 里存在（`docs(release)` 笔先于 tag 入库，裁定六十）；
- Release 页渲染 markdown——但我们的 notes 正文是纯文本（293 字符、零 `#`/反引号/`**`），显示为单段纯文本，与弹窗一致。

## 影响面（3 处）

### 1. `release.yml`
`Create draft release` 的 `with:` 加一行 `body_path`。**不动 `run:` 块。**

### 2. `release-compose.test.ts` 守卫（必须配套调整）
现有 L54-56 断言 `compose.slice(runStart)` 不含 `${{ }}`——`runStart = indexOf('run: |')`，而 `with:` 块在 `run: |` **之后**、被 slice 包含进去。**加 `body_path: ...${{ github.ref_name }}.md` 会让这枚守卫假红**（`${{ }}` 在 `with:` 数据通道里合法、但被 slice 误咬）。

**改法**：slice 范围从「`run: |` 到 step 尾」收窄到「`run: |` 到下一个 YAML 键（`with:`／`env:`／`- name:`）」——只锁 `run:` 脚本体、不咬 `with:`/`env:` 数据通道。

**配套负控**：临时把 `${{ }}` 塞回 `run:` 块 ⇒ 守卫必红（证收窄后仍有牙）；临时把 `${{ }}` 放进 `with:` ⇒ 守卫不红（证数据通道豁免生效）。两枚各交实测。

### 3. CI 行为
draft 创建时 body 被填充；Publish 后 Release 页可见正文。**不影响 `latest.json` 的 notes 管线**（那条在 Compose 步、独立）。

## 风险
- `body_path` 文件不存在时 `action-gh-release` 报错（fail）。我们的 `docs(release)` 笔先于 tag 入库 ⇒ 文件在 checkout 里存在。判据：`release-compose.test.ts` 已有「notes 文件在 tag 树内 EXISTS」的断言——保护已在位。
- `body_path` 内容是纯文本而非 markdown ⇒ Release 页显示为无格式段落。若将来想要格式化，需另写一份 markdown 版给 `body_path`、弹窗版仍走纯文本管线（方案 A 两份来源分工）。

## 需要配套的新判据清单
1. `body_path` 文件在 tag checkout 里 EXISTS（已有断言覆盖）
2. `with:` 块里的 `${{ }}` 不被注入锁误咬（守卫收窄＋负控）
3. Release 页 body 非空（Publish 后从公开链 `GET /releases/tags/v0.14.12` 取 `body` 字段、长度 > 0）
4. `body` 内容与 `latest.json` 的 `notes` 同源（都来自 `docs/release-notes-<tag>.md`）

## 不在本设计内的
- 不改 `latest.json` 的 notes 管线（剥标记/截句号/序列化——已验过）
- 不改 `release-published.yml`（G4 公开链路闸）
- 不动 `tauri.conf.json` 的 updater endpoints
- **不动 `release.yml`、不动 `release-compose.test.ts`**（等批下来再动，本稿只出设计）
