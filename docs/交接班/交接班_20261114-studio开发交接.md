## 4. 取证边界（写报告时不许糊）

- **`/users/login` 的 postData 在传输层已加密**（非 JSON），被动 Network 域**读不到 `device_id` 明文**；明文只能来自 `JSON.stringify` 拦截，而那个 hook 会污染实例、必须跑完即弃。
  ⇒ 独立复核能核的是**外部结果 200-vs-422**，不是那串密文。
- `sign_in` **打开即账号＋口令表单**：页面上没有「密码登录」文本节点（只有「验证码登录」toggle）。判断就绪要**数 `input[type=password]`**，别找切换标签文本。
- CDP 9222 验收必须用**独立 `WEBVIEW2_USER_DATA_FOLDER`** 起实例，否则复用既有 browser 组会双向假绿。
- 真机验收装版必须走 NSIS 标准安装到 `%LOCALAPPDATA%\DeepSeek++ Studio`，解到测试目录会永久锁在旧版本号。
