## 10. 复核结论格式

最终结论必须分成两段，禁止合并：

```text

```

代码级通过必须同时满足：

- Trae 提交范围干净；
- `npm run typecheck` EXIT=0；
- C1-F1 三个假绿点已变成真实断言；
- C1-F1 必测行为全覆盖；
- C1-F2 partial/warnings 从 memory-store 贯通到宿主和工具卡；

- entry.js 未被违规提交；
- DB 只读 7 项符合预期。

以下任一情况必须判“不通过”：

- 仍存在假绿测试；
- 只改测试未修实现；
- partial 只存在于底层、未到宿主或 UI；
- typecheck 靠忽略注释/降 strict 过；
- 提交夹带 entry.js、package-lock 或他席脏 hunk；
- DB 被写入或无法证明只读。
