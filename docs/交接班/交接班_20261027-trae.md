### T5（P2）：dpp 独立仓库 · DST 修复

**位置**：`E:\NAS\deepseek-pp\src\core\usage\stats.ts`。**独立 git 仓库，与 studio 主仓无关**。开工前 `cd E:\NAS\deepseek-pp; git status` 自查是否干净；**不干净就回报，别动**。

**根因**（HEAD 实测仍在，`:140`）：
```ts
const DAY_MS = 24 * 60 * 60 * 1000;
function getRecentDayKeys(rangeDays: UsageRangeDays, now: number): string[] {
  const today = dayKeyToTimestamp(toLocalDayKey(now));
  return Array.from({ length: rangeDays }, (_, index) => (
    toLocalDayKey(today - (rangeDays - index - 1) * DAY_MS)   // ← 用 24h 毫秒做"减一天"
  ));
}
```
DST 春进日 23h / 秋退日 25h → 减法跨切换点后不再落在本地 00:00。实测（America/Los_Angeles，2024-03-11 调 7 天窗口）：dayKeys = `[03-04…03-09, 03-11]`，**03-10 整天从统计消失**（`summarizeUsage` 里 `if (!dayKeySet.has(record.day)) continue` 直接丢），且窗口右移多算 03-04。秋季 25h → 同一 dayKey 出现两次，`dailyBuckets` Map 去重但 `days = dayKeys.map(...)` 把同 bucket 输出两次 → heatmap 重复格、`activeDays` 错、`calculateCurrentStreak()` 连带错。

**修法（日历减法，交给 Date 处理 DST 与月末进位）**：
```ts
function getRecentDayKeys(rangeDays: UsageRangeDays, now: number): string[] {
  const base = new Date(normalizeTimestamp(now, Date.now()));
  const year = base.getFullYear(), month = base.getMonth(), date = base.getDate();
  return Array.from({ length: rangeDays }, (_, index) => {
    const day = new Date(year, month, date - (rangeDays - index - 1));
    return toLocalDayKey(day.getTime());
  });
}
```
`dayKeyToTimestamp()`（`:120`，`new Date(year, month - 1, date)`）**是正确的**，可作换算基准。
