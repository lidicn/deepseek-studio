## 0. 口径先钉三枚（会影响所有下游读数）

**口径 1 — 「interceptor.ts」指哪个文件。**
计划写的 `interceptor.ts` = `src/inject/main-world-interceptor.ts`（下表统一称 **interceptor**）。本文不使用简称指代其他文件。

**口径 2 — 存在三份实现面，改哪份不等改完。**

| 面 | 路径 | 性质 | M3 是否要动 |
|---|---|---|---|
| TS 源面 | `src/inject/main-world-interceptor.ts`、`src/inject/tool-card-ui.ts`、`src/shared/continuation-prompt.ts`、`src/host/agent-loop.ts` | 唯一真源 | **要动** |
| 构建产物面 | `src-tauri/inject/entry.js`（git 已跟踪，1 个文件；含 `var MAX_NUDGES = 8`、`var RAW_TOOL_TAG_GLOBAL_RE`、`function autoContinueNudge` 等的转译副本） | **产物**：`package.json` 的 `build:inject` → `node esbuild.inject.mjs` 生成 | 源码删完必须 `npm run build:inject` 重新生成并一并提交，否则 Tauri 端仍跑旧纠偏 |
| 外部参照面 | `deepseek-pp/**`（本仓已跟踪 1041 个文件，是移植来源，非 studio 内核） | 上游参照 | **不动**（M3 与它无关） |

> 注：`deepseek-pp` 里的 `INLINE_AGENT_MAX_NUDGES`、`shouldNudge(text, executions, answer)` 三参签名与本仓的 `MAX_NUDGES`、`shouldNudge(visibleText)` 一参签名**不是同一个符号**。grep 会一并命中，归属表里已剔除。

**口径 3 — 「被 bot/** 依赖」分两档，别混。**
- **直接依赖** = `src/host/bot/**` 里有 import/引用该符号。
- **行为依赖** = bot/** 不 import 它，但它的删除会改变 bot/** 消费的运行时行为（emit 的事件内容、回合是否结束）。

对 8 枚符号，**直接依赖全部为 0**（实测：`src/host/bot` 下 grep 上述符号，零命中；bot/** 唯一跨线引用是 `../agent-loop` 的 `AgentLoop`/`AgentLoopEvent`/`AGENT_SENTINEL` 与 `AgentLoopOptions`）。但其中 **2 枚有行为依赖**（见 F1 派生结论与符号 4）。"零直接依赖" 不能读成 "删了不影响 B 线"。
