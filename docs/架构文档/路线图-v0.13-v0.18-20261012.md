## 一、项目全景

```
┌─────────────────────────────────────────────────────────┐
│                    统一底座（共用设计模式）                │
│  Tauri 壳 + Node sidecar + HTTP REST + checkpoint 原子写  │
├─────────────────┬───────────────────┬───────────────────┤
│  deepseek-studio │  yuanbao-audit    │   Lever-Hub       │
│  (主开发工具)     │  (24h 审计)        │   (MiMo 投喂)      │
│  端口 8760       │  端口 8761         │   端口 8762       │
│  快速迭代重启     │  常驻不重启        │   按需运行         │
└─────────────────┴───────────────────┴───────────────────┘
```

**三套系统运行时完全独立，代码不互相 import，仅共用设计模式和工具链。**

## 五、共用底座设计规范

三套系统共用以下模式（不共享代码，只共享设计）：

| 模式 | 规范 |
|---|---|
| HTTP 绑定 | 127.0.0.1，不绑 0.0.0.0 |
| readBody | 30s 超时 + 10MB 上限 |
| fetch | AbortSignal.timeout(30000) |
| 配置路径 | ~/.config/<项目名>/config.json |
| checkpoint | tmp + fsync + rename 原子写 |
| 端口分配 | studio=8760, yuanbao=8761, lever-hub=8762 |
| 日志 | JSONL 格式，内存上限 1000 行 |
