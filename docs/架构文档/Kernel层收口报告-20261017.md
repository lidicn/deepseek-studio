# Kernel 层收口报告

> 席1 · 2026-10-17

## 1. 模块导出清单

### src/host/kernel/message-history.ts（M2-1）
- `createMessageHistory()` → MessageHistory
- 方法：append / all / byRole / lastN / clear / size / snapshot / restore
- snapshot 带 `version: 1`；restore 版本不符抛错。

### src/host/kernel/history-store.ts（S3）
- `createHistoryStore({ read, write })` → HistoryStore
- `save(state)` / `load()` → 无数据返回 null；version 不符抛错
- `PersistedLoopState = { version: 1, history, round }`
- 注入式 read/write，无真实文件 IO。

### src/host/kernel/task-loop.ts（M2-3 + S2/S4/S5/S7/S9/S10/S11）
- `createTaskLoop(opts)` → TaskLoop
- `opts`：engine / history / maxRounds? / signal? / roundTimeoutMs? / store?
- `TaskLoopError`（带 .round / .cause）
- `TaskLoopStopReason`：completed / empty-response / no-tool-calls / timeout / aborted / max-rounds

### src/host/kernel/tool-bridge.ts（S8）
- `ToolExecutor` 接口：`execute(name, args?) → { ok, result?, error? }`
- `executeToolRecord(executor, rec)` → `{ record, content }`
- `createFakeExecutor(table)` 测试工具

## 2. 端到端数据流

```
user 消息
  │
  ▼
TaskLoop.run()
  │  history.append(user)
  │  ┌─── 循环 round = 1..maxRounds ───┐
  │  │ buildPrompt(history) → JSON 消息数组串
  │  │ engine.send(text)  ← 套 abort + per-round timeout
  │  │ history.append(assistant)
  │  │ for rec in toolCallRecords:
  │  │   history.append(tool, formatToolRecord(rec))
  │  │ computeStop() → stopReason?
  │  │ store.save({ history, round })   ← S11 checkpoint
  │  │ break if stopReason ≠ undefined
  │  └──────────────────────────────────┘
  ▼
返回 TaskLoopRoundResult
```

## 3. stopReason 语义表（优先级写死）

| 优先级 | 信号 | 触发条件 |
|---|---|---|
| 1 | timeout | send 超过 roundTimeoutMs 或引擎标 timedOut |
| 2 | completed | content 含 `<task_complete>` 信号 |
| 3 | empty-response | content 为空且 toolCalls=0 |
| 4 | no-tool-calls | toolCalls=0 但 content 非空 |
| — | aborted | AbortSignal 触发 |
| 兜底 | max-rounds | 跑满 maxRounds 未命中以上 |

## 5. 关键设计结论

- **零 nudge**：自驱链路全程宿主不发逼续提示词；一个工具回合 = 2 次 engine.send。
- **不碰禁改区**：model-engine.ts / agent-loop.ts / web-engine.ts / continuation-prompt.ts 全部只读 import。
- **注入优先**：engine / store / signal / executor 全走依赖注入，纯内存可单测。
