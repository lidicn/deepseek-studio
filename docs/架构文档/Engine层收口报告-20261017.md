## EngineSendResult

| 字段 | 类型 |
|---|---|
| content | string |
| toolCalls | number |
| timedOut? | boolean |
| toolCallRecords? | ToolCallRecord[] |
| completion? | 'complete' \| 'truncated' \| 'disconnected' \| 'unknown' |

## completion 四态判定逻辑

```
decideCompletion({timedOut, dispatchFailed, stopped}):
  dispatchFailed → disconnected
  timedOut       → truncated
  stopped        → unknown
  else           → complete
```

ApiEngine: finish_reason 'stop'→complete, 'length'→truncated, HTTP/network error→disconnected.

## WebEngine vs ApiEngine 对比

| 能力 | WebEngine | ApiEngine |
|---|---|---|
| transport | 页端 DOM dispatch | 原生 fetch |
| 完成检测 | 轮询快照稳定 | finish_reason |
| 重连 | tryReconnect() 3次线性退避 | fetch 自动重试（S8） |
| 指标 | metrics 注入 + nudgeRate | 无（未来加） |
| delta | onDelta 回调 | 无（未来 SSE） |
| 日志 | logger 注入 | 无 |

## ApiEngine 多模型适配

| Provider | finish_reason 归一化 |
|---|---|
| DeepSeek / OpenAI | stop→complete, length→truncated |
| Anthropic | end_turn/stop_sequence→complete, max_tokens→truncated |
| Ollama | 同 OpenAI |

## 错误分类

所有 HTTP 错误（401/429/5xx）和网络异常 → completion='disconnected'。

## destroy()

WebEngine.destroy() 清理 metrics + 缓冲；ApiEngine 无状态无需 destroy。
