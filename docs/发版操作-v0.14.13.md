# v0.14.13 发版操作（给你在网页上点的那几步）

这份不是 Release 正文。正文在 `docs/release-notes-v0.14.13.md`，只有那一页的内容才是发布页正文；本文件是内部操作说明，不要粘进去。

## 前置（由私聊 PM 完成，你不用做）

1. 全量闸绿（跑在终态上：版本号两处抬号 + 正文 + 操作单 + 规则文件 + 台账后批）。
2. `chore(release): 0.14.13`（版本号）与 `docs(release): v0.14.13 正文` 两笔已推送。
3. tag `v0.14.13` 已打并推送；CI 全绿（gate / cargo-check / release 三条）。
4. `releases` 里出现 **v0.14.13 (Draft)**，资产齐全：NSIS 安装包 + `.sig` + MSI 安装包 + `.sig` + `latest.json`；发布页正文已由流水线写入并逐字校验等值（不是 tag 注释）。

## 你要点的（大约一分钟）

1. 打开 https://github.com/lidicn/deepseek-studio/releases
2. 找到 **v0.14.13 (Draft)** → 右侧 **Edit**。
3. 确认 **Describe your release** 里的正文完整（应当是 `docs/release-notes-v0.14.13.md` 的全文；若不是，复制该文件全部内容粘进去替换）。
4. 勾上 **Set as the latest release**（这一勾必须勾；已踩过多次，不勾则 `releases/latest` 指针不推进，Studio 收不到更新提示）。
5. 点 **Publish release**。

## 发完之后

- 私聊 PM 会跑公开链路验证（资产可达、`latest.json` 指向、验签、发布闸），并核对更新端点返回的版本号与说明。
- 装版更新：Studio 内检查更新（若未自动提示，手动点一次"检查更新"）；安装 0.14.13 后**请退出旧实例再启新版**——旧实例占着本地端口，两装并存会让新实例起不来。
- 装版实测待办：新审批窗口首次弹出的现场取证、`cargo test` 四枚 `td05_*`（需本地端口空闲）、档位切 auto 后的审批链路走查。
