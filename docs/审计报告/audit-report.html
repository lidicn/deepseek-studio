Executive summary

deepseek-studio 是一个单人、高纪律的桌面 agent 工作台（Tauri WebView 壳 + Node 本地 API + 注入 chat.deepseek.com）。工程面整体成熟：单一 gate 真相（9 阻塞步 + 6 信息步）、strict TS、SSE/PoW 核心有测试与负控、发版线签名+draft+三向版本校验、本地 API 鉴权/限流/回环边界扎实（8.1/8.3/8.4/8.5 全绿）。

最严重的问题集中在 CI/CD 与质量闸：依赖面无人守——无 Dependabot，审计期 npm audit 命中 2 critical（tinypool RCE gadget）+ 2 high（undici，含 TLS 证书校验旁路），全部落在开发/测试工具链（vitest/esbuild/vite 依赖树）而非运行时依赖；同时安全尺（自研 SAST）挂在信息级，红灯不挡合并。第二个 Red 是 仓库与运维 的无根 README（上手知识散落在 AGENTS.md 与 docs/，入口组织缺失）。

信任边界与数据面是本仓的强项：SSE 帧解码器（审计日在改的文件）解析失败为文档化良性场景；记忆删除「归档→彻底删除」两态 + 事务审计 + VACUUM/secure_delete 物理清零，14.2 有实证 Green；密钥/PII 全仓+全历史 0 真命中（唯一 AKIA 模式命中为 wasm base64 巧合）。Amber 共 6 项，均为「预防性缺口或债务」而非活体暴露。无即时阻断项（无活体密钥、无真实 PII 提交）。
