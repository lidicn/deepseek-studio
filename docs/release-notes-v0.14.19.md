# DeepSeek++ Studio v0.14.19

一句话：本版修的是**「看起来像坏了、其实只是没说话」**的几处——设置页误报「宿主未连接」、工具说明和实际执行规则对不上、以及**上游中断时整轮回复被静默丢掉**。

## 一、设置页不再误报「宿主未连接，读不到」

现象：打开设置页，「sidecar 日志」「配置路径」两行停在「宿主未连接，读不到」，可工具其实能正常执行。

原因有两层，**本版两层都修了**：

- **说法层**：启动那一刻取授权凭据被限流一次，面板把这件事说成了「宿主未连接」。现在会如实说「宿主限流（冷却中），30 秒后自动重试一次」。
- **行为层**（更关键）：面板以前**只在程序启动时取一次**路径，之后不管怎么打开都不再重取——所以授权恢复后，那行字也永远停在错误状态。现在**每次打开设置页都会重取一次**，授权一恢复，真路径自己就回来了。

## 二、工具说明和执行规则对不上

工具说明里写着「优先用 PowerShell」，可实际执行器会把**双引号外的 `$ ; | > < &`** 直接判成「不支持 shell 语法」拒掉——**说明和实现自相矛盾，照着说明写必然被拒**。

现在两处说明（能力清单与工具目录）**逐字统一**为：

> 单条命令；双引号外不得含 `$ ; | > < &`。需要多语句或变量时改用 `params.argv` 数组（等价于 `powershell -NoProfile -Command "<整段脚本>"`）。

拒绝时的提示也**补成了可照抄的完整示例**（散文说法 + 可直接粘的 JSON 两种形态），不再只说「改用 argv 数组」却不说 argv 长什么样。

## 三、上游中断不再静默丢掉整轮

上游服务器返回错误、重试预算耗尽时，以前整轮回复可能被**静默丢弃**——你看到的是**什么都没发生**。现在会明确显示：

> 上游服务器暂时不可用，本轮已中断，请重试。

## 诚实说明

本版四处改动**都有自动化回归锁和负控**（摘掉修复即翻红、逐字节还原即复绿），全量闸 3,183 通过 / 1 跳过。但**「打开设置页看到真路径」和「上游中断看到提示」这两条，尚未在正式安装版上手工逐项走过**——如果你遇到面板还是显示「读不到」，或者中断时仍然什么都不显示，请把当时的界面文字发给我们，这属于要逐个核实的情况。

建议从 0.14.18 直接升级。
