### 入口规则（关键）

- **debug 构建**：只认仓库内 `<root>/src-tauri/host/main.mjs`，资源根 = 仓库根。
  刻意**不认** `target/debug/host/main.mjs` 同步副本 —— 副本可能是旧的，且认副本会让「改名 → 应回退 tsx」这条验证永远测不出来。
- **release 构建**：只认 `<resource_dir>/host/main.mjs`；缺了直接 `EXIT_HOST_MISSING`，不静默降级。
- **debug 且仓库内产物缺失**：回退 tsx 并打 WARN（保证开发者本机不被卡死）。

## 2. 真机暴露的两个真问题（都已修）

1. **`resource_dir()` 返回 verbatim 路径 `\\?\E:\...` → node 崩**
   `EISDIR: illegal operation on a directory, lstat 'E:'`（Node 的 CJS 入口解析把 `\\?\E:` 当盘符），cause：host entry 连续 6 次崩溃 → `sidecar gave up` → `/healthz` 120s 不就绪。
   修：`strip_verbatim()` 去掉 `\\?\` / `\\?\UNC\` 前缀后再交给 node（argv 与 `STUDIO_RESOURCE_ROOT` 都去）。
2. **dev 下 `resource_dir` = `target/debug`，静态资源只在仓库根**
   修：debug 构建资源根取仓库根（见上）。

## 4. 残余风险

1. `strip_verbatim` 会让 >260 字符的路径变脆（本应用远未到该长度）。若将来安装目录极深，需改回 verbatim 并让 node 用 `--preserve-symlinks`/自定义入口解析。
2. release 分支**未真机跑过**（没做 `cargo build --release` + `tauri build`）：`bundle.resources` 的映射语义只有打包时才生效，本轮只验证了 debug 构建走「仓库内产物」那条路。
3. 冷启动：`healthz` 就绪在脚本口径下 12.9–14.6s（含脚本轮询与负载），手动口径 bundle 与 tsx 都约 4s；两者都远小于 120s 预算，但 bundle 是否稳定快于 tsx 未做统计。
4. `bundle.resources` 的对象映射（`"../src/ui/agent.html": "src/ui/agent.html"`）仅按 Tauri v2 文档写，**未经过一次真实 `tauri build` 验证**。
