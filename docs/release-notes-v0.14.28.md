# v0.14.28 发版说明

发布日期：2026-11-21（tag `v0.14.28`；本版补齐**出资人点名要的「每个技能、每个 MCP 独立开关」的界面部分**——v0.14.27 只做了宿主能力，界面上的开关没接上）

## 这版修了什么

### 1. 技能面板的开关点了没反应（`eb74181`）

**现象**：v0.14.27 里技能面板上那枚开关是「死」的——点下去只是界面上的灯变了，**磁盘上什么都没写**，而且面板每次打开都把所有技能显示成开启状态（它自己写死了一个 `enabled: true`，把宿主返回的真实开关状态丢掉了）。

**修复**：
- 面板读取宿主返回的真实 `enabled`，不再写死；
- 点开关**真的落盘**（写 `disabledSkills` 清单），落盘成功后才更新界面状态；
- **落盘失败时界面回滚并显示错误**——不会出现「灯亮着但其实没关」的假状态；
- 注入面同步过滤：关掉的技能不再进每轮的提示词。

### 2. 聊天页的 MCP 列表里没有开关（`eb74181`）

**现象**：设置面板的 MCP 页每行只有「查看／去工作台编辑」，**没法就地开关**；而 MCP 开关是 v0.14.27 才有的功能，用户得去工作台那个明文编辑窗才能改。

**修复**：
- 每个 MCP 服务器右侧加一枚开关，**就地开关**；
- 开关状态以**管理面**回显为准（不是模型面）——禁用的服务器在管理面仍列出（否则关了就没法再开）；
- 落盘失败时保持原状并显示错误，不做「乐观翻转」；
- **凭据不流经聊天页**：开关只传「服务器 id ＋ 开或关」，由宿主进程内部去改配置文件，不走「整条配置 PUT 回传」那条会带着密钥来回跑的路。

### 3. 工作台的 MCP 编辑器没有「启用」项（`eb74181`）

**现象**：工作台那个能看见明文的 MCP 编辑窗，表单里根本没有启用与否这一项。

**修复**：
- 表单加「启用」勾选（默认勾选），列表里被禁用的服务器标「已禁用」；
- **勾选态保存时不带 `enabled` 键**（新配的服务器按旧行为落盘，行为完全不变）；只有明确取消勾选才写 `enabled: false`；
- 因此「只改 url 不会把已禁用的服务器静默重开」这条语义在编辑器里也成立。

### 4. 顺带修了一枚会让 CI 随机红的测试装置缺陷（`b13b2c3`）

**现象**：一枚测试用「把文件时间戳往前推 2 毫秒」来模拟配置变更。CI runner 的文件系统时间戳精度不同——实测**两次写盘落在同一毫秒桶的概率高达 48.85%**（本机是 0%），于是那枚测试有近一半概率随机红。

**修复**：改成**以上一次写盘的时间戳为基准 +1 毫秒**，保证严格递增 ⇒ 与机器速度、文件系统时间戳精度都无关。修法经 CI 实测：**碰撞率 48.85% → 0.00%**，该次 CI 三 job 全绿、零失败用例。**测试断言一个字未改**，只改写盘手法。

## 已知限制

- **剩余额度百分比做不了**：上游响应里只有布尔 `is_exhausted` ＋ 恢复时刻，没有任何剩余量数字，Studio 侧也没有额度查询接口。这版只做「撞墙时友好提示＋恢复时刻」，**不编数字**。
- **只识别纯 JSON 响应体**：若上游把额度墙包进 SSE 帧（页面端走 fetch 那条路），本版会漏判——现场实测撞墙走的是 XHR 路径（纯 JSON），已在代码注释里写明。
