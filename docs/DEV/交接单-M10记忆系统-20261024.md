## 2. 你的任务：M10-7 · `save()` 合并语义 + 容量上限 + 跨名去重

### 2.1 要改的三件

1. **未传字段保留原值**：同名 `save()` 时 `pinned` / `tags` 未传（`undefined`）→ 保留库里的旧值，而不是被重置成 `false` / `[]`。当前两处都把 `?? false` / `?? []` 当默认值写回。
2. **跨名内容去重**：同 `contentHash` 但 `name` 不同 → 返回既有 id，不新增行。
3. **容量上限**：新增 `MAX_MEMORIES`（建议 500，常量导出便于测试），超限时归档「最旧且非 pinned」的行，而不是硬删。

### 2.2 必须同批落的验收腿（缺一条算未交付）

- 置顶记忆同名 `save()` 不带 `pinned` → 仍置顶
- 带 tags 同名 `save()` 不带 `tags` → 原 tags 不变
- 同内容不同 name 第二次 `save()` → 返回第一次的 id，`stats().total` 不变
- 灌入 `MAX + 5` 条后 `stats().valid <= MAX`，且被挤出的是「最旧非 pinned」（置顶/user 档不得被挤）
- 去重命中时若原行已归档 → 复活原行（与 M10-5 同语义）

### 2.3 风险

`save()` 是 v1 兼容 API，`bot/types.ts` 的 `MemoryStoreV2` 契约签名不要动。`tests/desktop/memory-store-v2.test.ts` 里至少 3 条断言可能要同步调整——**调整前先在提交信息里写明「为什么旧期望是错的」**，不能靠改测试让红变绿。
