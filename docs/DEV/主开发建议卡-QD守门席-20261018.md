**证据**：`stopFlag.stopped` 全仓唯一复位点是 `src/host/agent-loop.ts:89`（`options.stopFlag.stopped = false`，位于 `AgentLoop.send()` 开头）——取法 `grep -rn "stopped = false" --include=*.ts src/host` ＝ `agent-loop.ts:89` ＋ web-engine 两枚同名局部变量。该复位是**被测试钉死的契约**：`tests/desktop/agent-loop.test.ts:93-94`「回合结束不再无条件清掉共享 stopFlag，停止意图保留到下次 send 开始时复位」。新主路 `desktop-host.ts:717-727` 调 `createTaskLoop(...).run()`，**永⛔ 经 `loop.send`** ⇒ 复位那行到⛔ 了。读取面：`desktop-host.ts:673` `isStopped: () => state.stopFlag.stopped` → `src/host/engine/web-engine.ts:244 / :310 / :332` 每轮轮询先 `if (options.isStopped?.()) { stopped = true; break; }`。

**⛔ 构造自动腿的原因**：开关已删、装配点⛔ 可注入（见 F-5），测试层够不到 `agent.sendMessage`。**人工验证步（真 app，2 分钟）**：面板发一条任务 → 点停止 → 再发一条 → 第二条若立刻结束且不驱动页面＝复现。
