# v0.14.11 发版操作（给你在网页上点的那几步）

这份不是 Release 正文。正文在 `docs/release-notes-v0.14.11.md`，只有那一页的内容才需要粘进 GitHub；本文件是我们内部的操作说明，不要粘进去。

## 前置（由私聊 PM 完成，你不用做）
1. 第 25 次全量闸绿（跑在终态上：版本号笔 + 正文 + 各席位收口件）。
2. `chore(release): 0.14.11` 与 `docs(release): v0.14.11 正文` 两笔已推送。
3. annotated tag `v0.14.11` 已打并推送；CI 三条 job 全绿（build+sign、published 闸、gate）。
4. `releases` 里出现 `v0.14.11 (Draft)`，资产齐全：两个安装包 + 两个 `.sig` + `latest.json`。

## 你要点的（大约一分钟）
1. 打开 https://github.com/lidicn/deepseek-studio/releases
2. 找到 **v0.14.11 (Draft)** → 右侧 **Edit**。
3. 打开 `docs/release-notes-v0.14.11.md`，**全选复制**，粘进 **Describe your release** 输入框（已经是纯正文，直接粘，不用改格式）。
4. 勾上 **Set as the latest release**（这一勾必须勾；已踩过三次，不勾则 `releases/latest` 指针不推进，Studio 收不到更新提示）。
5. 点 **Publish release**。

## 顺手可清（不影响功能）
- 旧的 **v0.14.10 (Draft)** 已按你的决定作废：Edit → 页面最下方 **Delete the release**。它的 tag `v0.14.10` 保留不删（发版历史不抹）。不删也不会影响 `latest` 指针，因为草稿不参与 latest。

## 发完之后
私聊 PM 会自动跑公开链路六件事验证（含验签资产、`latest.json` 指向、published 闸），然后在装版上做四线逐物定版现场取证；你只需要点 Publish 那一下。
