## 二、行为增量（相对 v0.26 仅存/取/压缩/解析）
1. **指令路由**：`@具体名` → 仅房内成员、保序去重（`mode:'mention'`）；空 targets 但发生过 @具体 → 仍 `mention` 不回退 `@all`/`none`；`@all` → `resolver.all()`（已注册且在房子集，非配置全集）；无 @ → 主持人兜底 `host-fallback`；否则 `none`。
2. **接力解析**：从 bot 回复里剥已注册 `@名` + `@all`（保留未注册 @名原文），未注册名进 `unresolved` 上报，不静默丢弃；`@all` 不算接力（防 N×N 自我广播）。
3. **轮次编排**：`generateReply` 构造注入（契约零侵入）；按波次顺序回，后者读前者净回复（`priorContents` + `spokenOrder` 顺序一致）；**`maxDepth` = 波数**（默认 1 只跑路由波，接力目标进 `pendingHandoff`；`maxDepth:2` 追加第 1 波，靠 `spoken` 集合截断 A→B→A）；**fail-soft**：单 bot `generateReply` 抛错 → 该位 `contents=''`、不解析其接力、整轮不炸。两轮编排 = 调用方连续两次 `planRound`（第 2 轮 trigger 为 @某人 消息），本层不续轮、不加 `planFollowUp`。

## 三、三条写死、勿「修正」
- 路由层 `@all`=全员轮流 / 接力层 `@all`=不算接力。
- 未注册人设名 → `unresolved` 上报，不静默丢弃。
- `maxDepth` 截断无限环。
