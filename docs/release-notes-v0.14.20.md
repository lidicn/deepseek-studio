# DeepSeek++ Studio v0.14.20

一句话：本版修的是**「你指定了技能目录，它却当没听见」**——设置页选的路径以前根本没落盘，重启就丢；现在真的写进配置、真的按它读，而且默认是**两枚根**而不是一枚。

## 一、指定的技能目录现在真的会记住

现象：在设置页「技能」那一栏选了自定义目录、点了「扫描」，看起来生效了；**一重启就回到默认**。

原因：那次选择**只活在内存里**，从来没写进 `config.json`。所以「指定了」和「跟着改」是两件事，本版把它们接上了——

- 点「扫描」→ 写进 `config.json` 的 `skillsDir` 键；
- 装版读取时**持久化的值压过默认链**（这条单独有一把回归锁）。

## 二、默认技能集合是**两枚根**，不是一枚

以前默认只认 `~/.agents/skills` 一个目录。现在默认是**两枚**：

| 根 | 位置 |
|---|---|
| 一 | `~/.agents/skills` |
| 二 | `<配置目录>/skills` |

规则：

- **存在与否都列**——不因为某一枚没建就少扫一枚；
- **同一个 id（目录名）先到先得**，顺序即优先级；
- 结果**按名称排序**，不随文件系统顺序抖。

## 三、清空＝**删键**，不是留一个空字符串

以前清空输入框，`config.json` 里留的是 `"skillsDir": ""`——**键还在**，于是「到底配没配」这件事永远说不清。

现在清空就是**把这个键删掉**，`readConfiguredSkillsDir()` 返回 `null`，回落默认两枚根。

## 四、面板文案与实现对齐

设置页占位文案原来写着「留空用默认 `~/.agents/skills`」——**只有一枚**，和上面第二条对不上。已改为：

> 技能目录路径（留空＝默认两枚：`~/.agents/skills` 与配置目录下 skills）

## 五、工程侧（用户无感）

`tests/desktop/grant-fail-visible.test.ts` 的偶发红已定位并隔离：`src/desktop/entry.ts:666` 的顶层 auto-init 在 **import 期**执行，而原守卫写在 `beforeEach`（import 之后才跑），**对首次 import 无效**——多装的那个宿主客户端其 30 秒冷却定时器在假定时器推进时照样调 `acquireGrant`，把计数从 2 抬到 4。改用 `vi.hoisted` 在 import 之前置空 `globalThis.__deepseekStudio`，插桩探针实测：**摘守卫 → 触发 1 次；带守卫 → 0 次**。
