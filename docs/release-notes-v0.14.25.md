# v0.14.25 发版说明

发布日期：2026-11-19（tag `v0.14.25`，自 `v0.14.24` 起进安装包的改动 3 笔行为面提交＋1 笔测试补格；其余为闸、文档与工具链提交，笔数不在本文写死——发布时以 `git rev-list --count v0.14.24..HEAD` 现算）

## 这版修了什么

### 1. 装版端口随启动摇摆、页面连不上宿主（根因修复，`edd8941`）

**现象**：同一枚 v0.14.24 装版 exe，多次启动行为不一致——11-17 17:39 那次宿主绑 8760（健康），11-19 00:39 与 01:56 两次宿主却绑到了 8761（开发树的端口）。装版页面注入层固定连 8760，宿主跑去了 8761，两边永不交汇：日志里 grant 签发了 200+ 次、ws 握手成功 0 次，主窗里工具执行／审批／记忆桥整条 agent 面断掉，且每次重启是否复现像抛硬币。

**根因**（源码级，本版实测复现三发两种结果即竞态证据）：启动时审批轮询器被拉起的时机早于「装版配置根覆盖」的写入，它抢先把开发树配置里的端口解析进进程级单次缓存，整个进程此后终身按错根的端口给宿主注入——哪个线程赢下竞态决定这次启动绑哪个口。

**修复**：把审批轮询器的拉起移到配置根覆盖写入**之后**，并补两枚回归锁（子进程形态锁＋接线顺序锁）钉死顺序；同时修掉连坐的审批轮询器错根取 token（装版上拿开发树的令牌轮询装版宿主＝401，审批自动窗两种形态都坏）。修复后装版必然回到自身配置根的 8760，与页面固定口对齐。

### 2. 开发树与装版彻底分档（`8590029` ＋ `504b834`）

开发树新增专用 identifier（独立单实例锁＋独立 WebView2 档案根，opt-in 切片：默认开发路径与打包面零改动）＋ 端口分档（dev 8761／装版 8760）＋ 页端宿主地址同源跟随（fallback 改读宿主注入值，不再硬编码）。从这版起，开发实例与装版互不抢占锁、档案与端口，取证窗口不再互相污染。

### 3. 设置面板端口显示改为现读（`504b834`）

设置面板的「宿主端口」从写死 8760 改为运行时现读，分档后两棵树各自显示真实端口。
