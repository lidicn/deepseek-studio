### 2.3 「≤120ms 预取时序」实测——**不达标**

- run 1：msel 发起 `1793426843911` → 请求发出 `1793426844076.72`，**+165.7ms**；select 结束 `1793426844476`（+554ms）
- run 2：msel 发起 `1793427588621` → 请求发出 `1793427588808.68`，**+187.7ms**；select 结束 `1793427589823`（+1203ms）

判定：
- 有界等待**按设计生效**（预算 120ms 到点即放行，页面侧还叠了技能刷新预算，故实测 165–188ms；XHR 路径为 `max(120,150)` 并行，`src/inject/main-world-interceptor.ts:1432-1436`）；
