## 判据 ①：三向版本一致（tag＝package.json＝tauri.conf.json）

- CI 已有门：`.github/workflows/release.yml` 步 `Verify tag matches version`（L45–L56）——`$tag`（`TrimStart('v')`）≠`package.json`.version 或 ≠`tauri.conf.json`.version ⇒ `Write-Error`＋`exit 1`。
- 发布前本地预跑（判据本体，tag 替换为目标 `v0.14.12`）：
  ```powershell
  $tag='0.14.12'
  $pkg=(Get-Content package.json -Raw|ConvertFrom-Json).version
  $conf=(Get-Content src-tauri/tauri.conf.json -Raw|ConvertFrom-Json).version
  "tag=$tag package=$pkg tauri=$conf"
  if($tag -ne $pkg -or $tag -ne $conf){ Write-Error 'tag/version mismatch'; exit 1 }
  ```
  判据原文与 `release.yml` L50–L56 逐字同构（`TrimStart('v')` 处本地用不带 `v` 的字面量，等价）。三读数（tag / $pkg / $conf）全部贴 PM-LOG，缺一枚不算过。

## 判据 ⑦：发布后正文真非空（手工验；自动闸故意降级，实物读数收尾）

- 命令原文（用户点 Publish 之后重读；`<repo>`＝上游仓 owner/仓名形，照判定② 占位、不写字面量）：
  ```powershell
  $rel = Invoke-RestMethod -Uri "https://api.github.com/repos/<repo>/releases/tags/v0.14.12" -Headers @{ 'User-Agent'='studio-release-gate' }
  "body_len=$($rel.body.Length)  draft=$($rel.draft)"
  ```
- 判据＝`body_len > 0` **且** `draft=False`，两读数原文贴 PM-LOG，缺一枚不算收尾。
- 为什么这一枚只能手工验：`253dd0d` 之后，`release-published.yml` 公开链路闸对 body 为空**只 `Write-Warning`、不 throw**（当时为避免"验签/产物/下载全正常的已发布版被打回 draft"，理由写死在该文件注释里）⇒"用户实际发布出去的那一版、页面上到底有没有正文"在发布后链路上**没有自动闸在钉**，自动硬信号只剩 draft 侧 Preflight。
