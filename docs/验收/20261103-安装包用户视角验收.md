### 步骤 7 · 收 ❌ P1 缺陷（现包红；已修复，待重新打包收口）

**缺陷（0.13.0 包，ad2fb89 基线，负控原样复现）**
- 安装版 `E:\NAS\_install_release`（release 重打包，含 workdir 修复、不含退出修复），appPid 19536，13:37:06 起，**空转 + 真实对话/工具调用共 84 分钟**，15:01:49 投递 WM_CLOSE（仅主窗 hwnd）
- p0 日志尾部（`logs/verify-exit/longsess-release-p0.log`）：
  ```
  [p0 …] exit-closure entered
  [p0 …] sidecar shutdown begin
  [p0 …] sidecar shutdown returned
  [p0 …] run_on_main_thread queued ok=false     ← 关键：teardown 闭包没进主线程队列
  [sidecar] stopped (graceful shutdown)
  ```
- 15:27:06 采集：**进程仍存活**（uptime 110 min，responding=True，handles=307，threads=12），而 webviews=0 / nodes=0 / port8760=0 —— **所有资源已释放，只有主进程本身不死**（`logs/verify-exit/exit-fix-negative-control.md`）
- 首验轮（`_dscore_e2e`，pid 20968）同症：11:19 关窗后 close-flow 走完（`run_on_main_thread queued ok=false`），主进程 90+ s 不退出，最终 Stop-Process 强杀（`logs/e2e-install/step2-stderr.log` 尾）
- **根因**：close-flow 的 exit-closure 依赖 `run_on_main_thread` 把 teardown 闭包排进主线程；长会话/多窗关闭时排队失败（ok=false）→ `app.exit(0)`/`process::exit(0)` 永不执行 → 进程挂死。短会话（Core 起停测试 1.9–3.7 s）排队成功故不暴露——**「起完就关」式安装测试永远测不出这条**

**修复 + 修复后安装版复验（绿）**
- 修复：`26e75ab`（前版 `d86d9ca`）`src-tauri/src/main.rs` +15/−5：`run_on_main_thread` 失败即强退 + 5 s 退出 watchdog
- 全量 gate：`gate-27-exithang-rerun` 通过（9 步阻塞 + 5 步信息，747.9 s）
- 修复后安装版（`_install_exitfix` / `_install_multiclose`，NSIS 重装）三场景复验：
  | 场景 | p0 原文 | 结果 |
  |---|---|---|
  | 正常关窗 | `queued ok=true` → `main-thread teardown entered` → `destroy main` → `terminated app webviews = 6` → `app.exit(0) returned` → `process::exit(0)` | 干净退出 |
  | 强制 queue-fail（负控修法兜底） | `queued ok=false` → `run_on_main_thread queue FAILED (main loop gone/rejected) → force exit(0)` → `force-exit: terminated app webviews = 6` | 强退成功 |
  | 连关多窗 | 同上强退路径（`multiclose-p0.log`） | 连关均退 |
- **结论：缺陷真实、根因明确、修复有效。但 0.13.0 被测包（CDBA2F21…，9:34 打包）早于修复（16:19 提交），step 7 对现包维持红；重新打包 + 复跑 step 7 后收口**

**派生发现（建议 P2）**：close-flow 会把窗口尺寸存成 `0x0`（`window-state.json`：0×0 @ −32000,−32000）；11:19 关窗后重启即恢复 0×0 窗口 → CDP 输入注入全失败（11:40–11:48 三轮探测），验收席手工修复 window-state.json 为 1280×800 后才恢复。建议 Core 随退出修复一并确认 close-flow 是否应存有效尺寸。
