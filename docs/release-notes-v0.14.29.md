# v0.14.29 发版说明

发布日期：2026-11-23（tag `v0.14.29`；本版补齐**设置弹窗「技能」页的逐项开关**——v0.14.28 只把开关做进了同一弹窗的 MCP 页和技能管理浮层，设置弹窗的技能页还是光秃秃的）

## 这版修了什么

### 1. 设置 → 技能页每行没有开关（`f34a2b7`）

**现象**：v0.14.28 装好后，设置弹窗的 MCP 页每行已经有开关，但**同一个弹窗的技能页每行只有名字和描述、没有开关**——出资人一打开设置就看出「MCP 有、技能没有」。技能管理浮层里那枚开关是有的，但那不是他打开的界面。

**修复**：
- 设置 → 技能页每行加一枚开关，与 MCP 页完全同构（位置、尺寸、点击手感一致）；
- 状态以宿主 `skill.list` 返回的真实启用态为准（缺键＝启用），面板里不再有任何写死值；
- 点开关调宿主 `skill.enabled.set` **真落盘**（写配置的 `disabledSkills` 清单），**成功后才以宿主真源重新拉取刷新**——不做乐观翻转，灯不会先亮再回弹；
- 关掉 ⇒ 清单里出现该技能 id，注入面下一轮不再注入；重开 ⇒ **整键删除**，不留下空数组；
- 落盘失败 ⇒ 开关保持原状＋行内红字报错，不会出现「灯亮着但其实没关」。

### 2. 同族入口的排查结论（本版未改，写清查过）

- **技能管理浮层**（侧边栏「插件·技能·伙伴」）：每行开关已有（v0.14.28），真落盘，本版不动；
- **输入框打 `/` 的技能候选弹层**：是选择器不是管理面，按设计**不加开关**；
- **右侧栏「已启用技能」卡片**：只读展示，不加开关。

## 已知限制（沿用 v0.14.28）

- **剩余额度百分比做不了**：上游响应里只有布尔 `is_exhausted` ＋ 恢复时刻，没有剩余量数字，Studio 侧也没有额度查询接口。只做「撞墙时友好提示＋恢复时刻」，**不编数字**。
- **额度墙只识别纯 JSON 响应体**：若上游包进 SSE 帧（页面端 fetch 那条路）会漏判；现场实测撞墙走 XHR（纯 JSON），已在代码注释写明。
