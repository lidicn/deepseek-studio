## 5. 任务分解

### A-1 · 先类型后实现

`task-loop.ts` 导出（签名可微调，但 run 必须 async、必须回填、必须给 stopReason）：

```ts
export type TaskLoopStopReason =
  | 'completed'
  | 'no-tool-calls'
  | 'timeout'
  | 'max-rounds';

export interface TaskLoopRoundResult {
  readonly round: number;
  readonly content: string;
  readonly toolCalls: number;
  readonly toolCallRecords?: readonly ToolCallRecord[];
  readonly stopReason?: TaskLoopStopReason;
}

export interface TaskLoopOptions {
  readonly engine: ModelEngine;
  readonly history: MessageHistory;
  readonly maxRounds?: number;   // 默认 1
}

export interface TaskLoop {
  run(userText: string): Promise<TaskLoopRoundResult>;
}

export function createTaskLoop(opts: TaskLoopOptions): TaskLoop;
```

### A-2 · run() 实现顺序（固定，不许跳步）

1. `history.append({ role: 'user', content: userText })`
2. 从 `history.all()` 取上下文 → 拼成 `engine.send()` 要的输入（**先看 ModelEngine.send 真实签名**）
3. `const result = await engine.send(...)`
4. `history.append({ role: 'assistant', content: result.content })`
5. 若 `result.toolCallRecords` 存在，**逐条** append `role: 'tool'` 记录（含 tool 名 + ok + error）
6. 算 stopReason：`timedOut` → timeout；`toolCalls === 0` → no-tool-calls；否则 undefined
7. 返回 `TaskLoopRoundResult`

### A-3 · 测试（≥ 10 用例）

必须覆盖：
- `toolCalls:3` + `toolCallRecords:[3条]` → history 多出 1 assistant + 3 tool
- `toolCalls:0` → `stopReason === 'no-tool-calls'`
- `timedOut:true` → `stopReason === 'timeout'`
- `toolCallRecords:undefined` 但 `toolCalls:2` → **不崩**
- 连续两次 `run()` → history 累积（不是覆盖）
- `history.snapshot()` 能取到回填后的完整状态

**假引擎自己写**，别 import 真 WebEngine。

### B · 阶段 B（选做）

`while (round < maxRounds && !stopReason) { ... }`。每轮重新算 stopReason，轮间不能漏回填。
