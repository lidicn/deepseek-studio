## 3. 任务（按序做完）

### 3.1 实现 MessageHistory

文件：`src/host/kernel/message-history.ts`

必须提供：

```ts
export type ChatRole = 'system' | 'user' | 'assistant' | 'tool';

export interface ChatMessage {
  readonly id: string;          // 稳定唯一 id
  readonly role: ChatRole;
  readonly content: string;
  readonly toolCallId?: string; // role='tool' 时关联的调用
  readonly createdAt: number;
}

export interface MessageHistory {
  append(msg: Omit<ChatMessage, 'id' | 'createdAt'> & { id?: string }): ChatMessage;
  all(): readonly ChatMessage[];
  byRole(role: ChatRole): readonly ChatMessage[];
  lastN(n: number): readonly ChatMessage[];
  clear(): void;
  size(): number;
  /** 导出可 JSON.stringify 的快照，带版本号 */
  snapshot(): { version: 1; messages: readonly ChatMessage[] };
  /** 从快照恢复；版本不认识要抛错，不许静默降级 */
  restore(snap: unknown): void;
}

export function createMessageHistory(opts?: { idFactory?: () => string; now?: () => number }): MessageHistory;
```

硬要求：
- **纯内存、零 IO、零依赖**（不 import 任何 src 内其他模块）
- `append` 返回落库后的完整对象（含生成的 id 与 createdAt）
- `restore` 遇到 `version !== 1` 必须抛错（存储/协议变更硬要求：带版本字段 + 可回退读取）
- `all()` 返回只读视图，调用方改不动内部数组
- `idFactory` / `now` 可注入，方便测试确定性

### 3.2 测试

文件：`tests/desktop/kernel-message-history.test.ts`，**≥ 12 个用例**，至少覆盖：

1. append 生成唯一 id 与递增 createdAt（注入 now）
2. append 时显式传 id 则用传入的
3. all() 顺序 = 追加顺序
4. all() 返回值不可变（改它不影响内部）
5. byRole 过滤正确
6. lastN(n) 取尾部 n 条；n > size 时返回全部
7. lastN(0) 返回空
8. clear 后 size=0
9. snapshot 形状稳定（含 version:1）
10. snapshot → JSON.stringify → JSON.parse → restore 往返一致
11. restore 遇到 version:2 抛错
12. restore 遇到非对象/缺 messages 抛错
