## 重要发现（写入最终报告）
- **F1：engine.health() 不可信**。无页面时 `chat-read` 走 Node rehydrate 兜底，返回 `{ok:true, snapshot:{...}}`，WebEngine.health() 据此返回 ok=true。必须额外校验 `data.messages` 是数组才算真页面在线。live-health.ts 已加此校验。
- **F2：completion=truncated，每轮拖满 120s 看门狗**。首条「请只回复两个字：你好」实际拿到了 content="你好"，但稳定性判定（stableHits=2）始终不收敛，poll 直到 stepTimeoutMs=120s 看门狗才返回 truncated。124s/轮。这是 V2 nudgeRate 要量化的核心问题。
