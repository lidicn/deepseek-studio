## 5. 红线（不可回退）

1. 授权先于执行：任何工具必须过 grant + policy + consent 三闸
2. 错误码复用 CONTRACTS §6.1 七码，不发明新码
3. 工作区边界唯一入口 `workspace.resolveWithin`，fail-closed
4. 上游 `deepseek-pp/src/core/**` 零修改
5. 纯函数包不 import `src/host/**`
