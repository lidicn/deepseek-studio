## 4. 工具执行稳定性

### 4.1 D-1：Windows `.cmd/.bat` 路由

**状态：DONE（`f6393a2`）**。PATH/PATHEXT 解析、无扩展名影子文件续查、仅批处理走 `cmd /c` 已落地；真实 `npx` 已跑通。

**问题**：`shell_exec` 只识别硬编码 cmd 内建命令；`npx`、`pnpm`、`yarn` 等 `.cmd/.bat` 直接 spawn 会 ENOENT。

**修复原则**：

- 可执行解析必须基于 PATH + PATHEXT，不得继续堆命令名单。
- 只有最终命中 `.cmd/.bat` 才走 `cmd /c`。
- `.exe` 与普通可执行文件继续 `shell:false` 直接 spawn。
- 管道/重定向继续拒绝。
- 走 `cmd /c` 的参数继续拒绝 `& | < > ^`。

### 4.2 D-2：ENOENT hint

**状态：DONE（`0d60bc6`）**。`windowsEnoentHint` 仅在 win32 + ENOENT 时给出 `powershell -Command` 指引；同步抛错与 `child.on('error')` 两条路径都已覆盖，非零退出/超时不误报。

**问题**：PowerShell cmdlet 直接 spawn 失败时，只返回 `spawn-failed`，没有可操作指引。

**修复原则**：

- Windows ENOENT 时返回 hint，提示 PowerShell cmdlet 应写成 `powershell -Command ...`。
- 宿主已有的 `-EncodedCommand` 中文路径保护不能被绕过。
- 不根据命令名猜测并自动执行 PowerShell。

不是代码缺陷。agent 汇报必须带生成时刻；后一份覆盖前一份时要明确写“作废上一条状态”。

## 4A. 审批授权 v2（P0，v0.8 新增）

### 4A.1 核心拆分

| 轴 | 回答的问题 | 取值 |
|---|---|---|
| `policyMode` | Agent 可以访问多宽的执行范围 | `workspace / auto / full`（`ask` 兼容旧值） |
| `approvalClass` | 这类工具是否需要人工确认 | `none / mode / always / hard-deny` |
| `grant` | 用户批准后，放行到什么对象、多久 | `once / turn / session / project / global / temporary` |

**`full` 最终定义**：执行范围完全放开，安全阀仍然保留。它只影响 `mode` 类文件/命令工具，不允许绕过 `always`、`hard-deny`、未知来源、writable-root 缺失与敏感路径规则。

### 4A.2 工具分级

- `mode`：`file.*`、普通 `shell.exec`、`mcp.test`。
- `always`：`policy.set`、`workspace.set`、`memory.delete`、`memory.purge`、`memory.unarchive`、`chat-send`、`python.exec`、`mcp.call`、`mcp.save`、`mcp.remove`。
- `none`：其余现有只读/低风险工具；`memory.save` 本批保持现状，不静默重分级。
- `hard-deny`：磁盘格式化、关机/重启、盘根递归删除、敏感凭据路径、未知工具/来源等动态规则。

### 4A.3 授权时间

- `once`：单次调用。
- `session`：`sessionId/botId + workspaceHash + toolId + actionClass + canonicalTarget`；会话结束、Bot 断开、工作区/策略变化、用户撤销、进程重启即失效，不以 10 分钟 TTL 为主。
- `project`：只能由用户在设置页显式创建、预览、撤销，不能由审批弹窗创建。
- `temporary`：仅高危精确目标的 10 分钟临时放行，必须有倒计时与撤销入口。
- `always` 工具不得发放普通 `session/project` grant；`hard-deny` 永远优先。
- `internal-bot` 的 `chat-insert/chat-send` 预授权必须标源，不能冒充用户授权。

### 4A.4 执行顺序

`工具登记/来源 → hard-deny → workspace/resource deny → deny 规则 → always 新鲜确认 → mode 有效 grant → policyMode → fail-closed`。

完整任务卡见 `docs/交接班/交接班_20261026.md` §18.5 + §19（§3-§8 保留为设计依据）。
