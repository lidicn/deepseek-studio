### 专项建议：回环信任点排查（可作为 R3 的前置小任务）

R1-01、R2-02、R2-03 三处 P1 同源——把「本机回环」当作信任边界。这不像三次独立笔误，更像一处认知偏差的多次复现。建议：

```
全仓 grep 以下模式，逐点判定「是否把回环当成了鉴权」：
  127.0.0.1 / localhost / [::1] / 0.0.0.0
  hostname === / endsWith / includes
  isLocalOrigin / isPnaAllowedOrigin / LOCAL_HOSTS
```

判定标准只有一条：**该处代码是否因为「来源是本机」而跳过了本应执行的鉴权/校验。** 若是，即为同类缺陷。

预计可在一个小任务内完成，产出并入 R3 报告附节。
