# 契约守门注释假阳性修复（tools/contract/check.ts）— Gate 执行记录

- 日期：2026-11-01
- 派单：Studio-PM（gate-batch3-final 阻塞修复卡）
- 域：tools/contract/**（Gate）、tests/desktop/tools-contract.test.ts（PM 本卡授权）

## 1. 事故与根因

全量 gate `logs/gate-batch3-final.log` 中 `tools-contract` 报 `task-loop.ts` 三处违规：

```
[TaskLoop] TaskLoopStopReason 出现非法值 'disconnected'
[TaskLoop] TaskLoopStopReason 出现非法值 'read-no-data'
[TaskLoop] TaskLoopStopReason 出现非法值 'read-no-data'
```

根因（两处叠加，缺一不可）：

1. **合法值清单没跟上**：Core F6 给 `TaskLoopStopReason` 新增 `'read-no-data'`（语义：页还活着、引擎连续读不到数据，与 `empty-response`=页端消失/传输断二分；Core 已确认），`check.ts` 白名单未同步。
2. **扫描不剥注释**：`checkTaskLoop` 用 `([\s\S]*?);` 抓 union body，body 内部的 JSDoc（`src/host/kernel/task-loop.ts:36-41`，含 `completion='disconnected'` + `reason='read-no-data'`）被当成员扫进去 → 假阳性。

定位信息来源：Core 群消息（三处注释：task-loop.ts:37、web-engine.ts:61/93；本守门只扫三个目标文件，web-engine.ts 不在目标清单，其注释本就不参与 TaskLoopStopReason 判定）。

## 4. 已知限制（记录在 check.ts JSDoc）

- `stripComments` 不递归处理模板字符串 `${}` 内嵌套反引号；三个目标文件实测无此形态，用例 #12–#15 锁定主行为。
- 正则字面量识别用「前一个有效 token」启发式（return/typeof/case 等关键字后视为正则），覆盖常见形态；极端未闭合正则有换行容错，不吞整行。
