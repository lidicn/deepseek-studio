## 一、素材事实（先纠正）

- 唯一素材：`docs/设计稿/app-icon-v1.png`（**未覆盖原图**）。
- 实测该文件魔数为 `FF D8 FF EB`，实为 **JPEG**（被改名为 .png），尺寸 2048×2048，468,724 B。
- `tauri icon` 按扩展名按 PNG 解码，报 `Invalid PNG signature`。处理：用 GDI+ 在临时目录把 JPEG 解码重编码为真 PNG（魔数 `89 50 4E 47`），**原图未改动**，再喂给 tauri。
- 执行命令：`npm run tauri -- icon <临时真PNG>`（自动缩放，未手工缩放）。
