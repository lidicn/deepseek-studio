### sidecar 关闭残留修复

- 现场关闭应用后发现：窗口已退出、8760 已释放，但 `cmd.exe → node.exe → npx-cli → tsx → api/main.ts` 进程树仍在。
- 根因有两层：
  - Windows 上 `Child::kill()` 只结束 `cmd.exe` 包装层，不结束 `npx` 启动的 node 子树；
  - 原关闭线程只发送信号，监管线程持有互斥锁且未被及时唤醒，应用 500ms 后先退出，清理来不及执行。
- 修复：关闭路径改为共享原子关闭标志 + 同步等待监管线程停止；Windows 用 `taskkill /PID <pid> /T /F` 结束整棵进程树，并在最多 `GRACEFUL_TIMEOUT + 1s` 内循环确认。
- 复测：正常启动后 `/healthz=200`；关闭主窗口后应用退出、8760 释放、sidecar 进程链无残留。
- `cargo check`：0 errors，0 warnings；`cargo build`：成功。
