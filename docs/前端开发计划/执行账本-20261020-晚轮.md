## 五、P2 · 手机端 PWA

### 5.1 安全前置（本项最重要）

`/agent` 路由原本**免鉴权**，真实 API 令牌内嵌在 HTML 里
（`server.ts` 把 `__STUDIO_API_TOKEN__` 替换成 `config.json` 的 token）。
只要服务绑 127.0.0.1，威胁模型与"本地进程本就能读 config.json"等价。
一旦为手机访问绑 0.0.0.0，同局域网任何人都能拿到完整令牌控制 agent。

因此新增 `src/api/agent-lan-access.ts`：
- 局域网模式默认关闭，需 `DEEPSEEK_STUDIO_LAN=1` 显式开启，启动打三条 ⚠️ 警告
- 非 loopback 请求必须带 `?pair=<配对码>`，否则 **403 且不返回任何内嵌令牌内容**
- 403 响应体不泄露配对码；配对码用去混淆字符集（无 `0`/`O`/`1`/`I`）
- 开了 LAN 但码为空串 → fail-closed 拒绝一切非回环
- loopback 永远放行（桌面端自己的用法，与开关无关）

**修掉一个自己引入的逻辑漏洞**：最初未配置 `PAIR_CODE` 时只在日志里生成随机码，
服务端收到的仍是空串，`decideAgentAccess` 会拒绝所有非回环请求——
日志成了骗人的摆设。改为生成后真正传入服务端。

### 5.2 移动视口判定

新增 `isMobileViewport()`：区分"桌面窗口被拖窄"（显示桌面提示）与
"手机/PWA 本来就窄"（按 compact 正常用）。判据 `pointer: coarse` + `hover: none`，
UA `Mobi|Android|iPhone|iPad|iPod` 兜底。移动端写 `html.is-mobile` 供 CSS 消费。

### 5.3 PWA 资源

- `agent.webmanifest`：`scope` 限 `/agent`，不把整个域变成 PWA
- `icon-192.png` / `icon-512.png`：从 `src-tauri/icons/icon.png` 真缩放（GDI+ HighQualityBicubic），
  哈希与源图不同，确认非同图复制
- `agent-sw.js`：只缓存白名单静态壳；`/agent` **显式 network-only**
  （含令牌，与响应头 `no-store` 双保险）；`activate` 清理旧缓存
- CSS：16px 输入框防 iOS 自动放大、`env(safe-area-inset-*)`、44px 触控目标、顶栏换行

**验收**：新增 `tests/desktop/agent-lan-access.test.ts` 21 例（配对码判定矩阵、
IPv4-mapped IPv6 归一、403 不泄露码）、`tests/desktop/mobile-viewport.test.ts` 8 例
（移动端不降级、桌面端仍降级）、`tests/desktop/agent-pwa-assets.test.ts` 15 例
（manifest 结构、HTML 接线、SW 缓存策略、图标真实存在）。
