# 旧 Shadow API 收口清单（2026-10-20 · W5）

## 〇、事实前提（先纠正概念）

`createShadowContainer()`（src/ui/studio-ui-core.ts:102）返回的 `shadow` 就是 `container` 本身
（`return { container, shadow: container }`），**并不是真 ShadowRoot**；`injectStyles()` 把 css 追加到
全局 `<style>` 标签，`_shadow` 参数实际未使用。因此仓里并不存在「两套 Shadow API」：

- **真 Shadow API** 只有 `mountShadowRoot()`（src/ui/shadow-root.ts，`host.attachShadow({mode:'open'})`），
  目前仅 `src/ui/focus-mode.ts:61` 使用。
- `createShadowContainer/injectStyles` 是「普通 div + 全局样式」的旧封装，名不副实。

本清单按**实测可达性**给每个文件三态之一：`migrated` / `deprecated-unreachable` / `retained-with-reason`。
本期不做物理删除，只标注状态与去向。
