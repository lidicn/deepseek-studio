## 八、AI 无法代做的部分（诚实标注）

- 所有**视觉判定**（是否白屏、颜色是否正确、遮拦、滑入动画是否顺畅）——jsdom 无布局引擎。
- **真实登录流程**（扫码、风控）。
- **真实 WebView 行为**（Tauri WebView2 与 Chrome 的差异）。
- **窄屏拖拽的实时重排**（jsdom 无 `resize` 触发的真实 reflow）。

以上只能由人点一遍。本文档存在的意义就是把这些环节固定下来，避免每轮都要重新想"该验什么"。
