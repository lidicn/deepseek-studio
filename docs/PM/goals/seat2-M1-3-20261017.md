### 3.2 写一个最小探针（不接线、不跑真模型）

文件：`src/host/kernel/pi-transport-probe.ts`

目标：构造一个**假的 transport**（返回预设的假 delta 序列），喂给 pi-agent-core 的 agent-loop，看它能不能跑通一个 turn。

硬要求：
- **不 import `web-engine.ts` / `agent-loop.ts`**（只 import pi 的类型）
- 不发起任何网络请求
- 若 pi 的 API 要求某些必填实现，把它们 stub 到能编译
- 若无法在 2 小时内让它跑通，**停手**，把卡点写进报告（这本身就是 D2 的答案）

### 3.3 测试

`tests/desktop/pi-transport-probe.test.ts`，≥ 4 个用例：

1. 假 transport 能被 pi 的 loop 接受（不抛错）
2. 跑通一个 turn 并收到至少 1 个 delta
3. 工具调用的类型能构造出来（哪怕只是 stub）
4. 断言：探针模块**没有** import web-engine / agent-loop（可用读取自身源码字符串断言）
