# studio PM 制度 · 入口

> 建立：2026-10-17
> 目的：让 PM 角色（无论哪个 agent 担任、无论对话是否中断）都能在 5 分钟内被接手。
> 单写者：docs/PM/** 只由 PM 角色写。其他 agent 不写这里，只在自己窗口报，由 PM 转录。

---

## 一、为什么需要这个

PM 跑在 dpp（deepseek-pp）里，有对话上限、容易出问题。一旦中断：

- 对话上下文没了
- 谁在做什么、做到哪、为什么这么做，全在上下文里
- 新 agent 要从零调研，成本极高，且容易做出与既有决策冲突的动作

所以：**所有状态必须落盘，且落盘格式要让人或 agent 读 5 分钟就能干活。**

这不是写日记。日记是给自己看的；这是**交接凭证**，是给下一个不认识你的 agent 看的。

---

## 二、5 分钟接手路径（新 agent 严格按此顺序）

| 步 | 读什么 | 花多久 | 得到什么 |
|---|---|---|---|
| 1 | 本文件 | 30s | 制度是什么、文件在哪 |
| 2 | STATE.md | 2min | **现在项目在哪一步**（唯一真相） |
| 3 | DECISIONS.md 最后 5 条 | 1min | 已经定过什么，别推翻 |
| 4 | RULES.md 常设段 | 1min | 什么绝对不能干 |
| 5 | log/今天.md 末尾 | 30s | 刚才发生什么、断点在哪 |

读完就能干活。

**明确不要做的**：不要先读全仓库、不要先跑测试、不要先看 git log。那些是接手**之后**的事。先花 5 分钟读上面 5 个，比花 1 小时自己调研强。

---

## 三、文件职责（严格不重叠）

| 文件 | 写什么 | 写方式 | 谁写 |
|---|---|---|---|
| README.md | 制度本身 | 极少改 | PM |
| STATE.md | **当前状态快照**：里程碑、在飞、阻塞、下一件事、硬证据 | **覆盖式重写** | PM |
| DECISIONS.md | 决策台账：定了什么 + 为什么 + 被谁推翻 | **只增不改** | PM |
| RULES.md | 规章：常设铁律 + 临时规则（带失效日） | 增删皆可 | PM |
| log/YYYY-MM-DD.md | 当日轨迹：时刻 + 动作 + 证据 | **只追加** | PM |

**为什么拆成 4 个而不是 1 个**：因为它们的写方式不同（覆盖 / 只增 / 可改 / 只追加），读者的问法也不同（现在在哪 / 为什么这样 / 什么不能干 / 刚才发生什么）。混在一个文件里，两种事故必然发生：状态被埋进历史，历史被状态覆盖。

**铁律：STATE.md 是项目状态的唯一真相。任何文档与它冲突，以它为准。**
（与各线任务文档的层级关系见 RULES.md R-2）

---

## 四、PM 每次输出的固定动作

每轮对话结束时，PM **必须**做三件事，缺一不可：

1. 更新 STATE.md（哪怕只改一行「最后更新」）
2. 往 log/今天.md 追加一段（时刻 + 做了什么 + 证据）
3. 若有新决策，追加 DECISIONS.md

**不写 = 这一轮等于没发生。** 因为下一任看不到。

这是 PM 角色唯一的硬性 KPI：**不是做多少判断，是让判断留下来。**

---

## 五、会话中断时的断点约定

每次会话结束时，在 log/今天.md 末尾留一行：

```
⇦ 断点：<一句话说清在哪停的>。下一任从 STATE.md §4 开始。
```

STATE.md 的 §4「下一任第一件事」必须与此一致。两处都写，是因为接手人可能先读到任一处。

---

## 六、极简版（如果觉得重）

如果某天觉得 4 个文件维护成本太高，**最小可用是 2 个**：STATE.md + log/。

但即使退化到 2 个，也必须保留两条：
- STATE.md 覆盖式重写（不能变成流水账）
- log 末尾留断点标记

DECISIONS.md 和 RULES.md 可以合并进 STATE.md 的附录，但**不能没有**——它们是防止下一个人推翻已定决策的唯一屏障。

---

## 七、操作注意（踩过的坑）

**PowerShell here-string 写 Markdown 会失败。** here-string（@'...'@）内含反引号会被误解析，导致 WriteAllText 的路径被 CRLF 污染，报 Could not find a part of the path。

**正确写法**：用单引号字符串数组 + WriteAllLines：

```powershell
$L=@('# 标题','','正文','')
[IO.File]::WriteAllLines($p,$L,(New-Object Text.UTF8Encoding($false)))
```

另外：.NET 的 [IO.File]::ReadAllText / WriteAllText 用**相对路径**时按进程 CWD 解析，不是 cd 后的目录。**一律传绝对路径。**
