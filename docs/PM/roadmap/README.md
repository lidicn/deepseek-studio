# 路线图工作制（取代 goal 卡片制）

> 建立：2026-10-17 11:20 | 制度版本：R1
> 背景：卡片制让三席每交付一次就停下来等 PM 审核，人多的优势完全没发挥。改成路线图制。

---

## 一、一句话

**每个席位有一份路线图，里面有 5-6 个串行阶段。席位做完一个阶段就落盘一份进度文件，然后立刻开始下一个阶段，不停下等审核。PM 只更新路线图，不卡节点。**

---

## 二、三份路线图（唯一任务真相）

| 席位 | 路线图 | 长目标 |
|---|---|---|
| 席1 | `roadmap/seat1-kernel.md` | 内核运行时：从 TaskLoop 基础版到可靠的多轮自驱 + 持久化恢复 |
| 席2 | `roadmap/seat2-engine.md` | 引擎层：WebEngine 成为唯一 transport，具备完成检测、指标、断流恢复 |
| 席3 | `roadmap/seat3-harness.md` | Harness 工具链：把「能证明系统是对的」工具化 |

**每份路线图里有阶段列表 S1/S2/S3…，每阶段含：目标、落点文件、验收命令、状态标记。**

---

## 三、席位的跑法（三席统一）

```
打开自己那份路线图
  ↓
找第一个状态为 [ ] 的阶段
  ↓
做完（含验收命令跑绿）
  ↓
落盘 progress/seatN-Sx-yyyymmdd-HHmm.md（简短，见模板）
  ↓
回路线图把该阶段改成 [x] 并写一行结果
  ↓
立刻开始下一个阶段 —— 不要停，不要等回复
  ↓
（循环，直到路线图全部 [x] 或触发停手条件）
```

**关键：不要向 PM 请示。** 路线图就是授权。阶段之间没有审核闸门。

---

## 四、进度文件格式（替代交付卡，但更短）

落盘到 `docs/PM/progress/seatN-Sx-yyyymmdd-HHmm.md`：

```
# 席N · Sx · <阶段名>

## 做了什么
（2-4 行，列改动文件）

## 验收原始输出
（粘贴命令与输出，不要写「已通过」）

## 遗留/风险
（1-3 行；没有就写「无」）
```

**不要写自述、不要写思路过程。** PM 只看验收原始输出。

---

## 五、PM 的动作（唯一的干预点）

PM 只在三种情况下动路线图：

1. **插入新阶段**：发现缺口 → 在该席路线图里加一个 Sx
2. **调整顺序**：某阶段被阻塞 → 把它标 [BLOCKED] 并把后面的提前
3. **补验收命令**：某阶段的验收不够硬 → 改那一行

**PM 不需要每阶段审核。** 定期（比如每 30 分钟）扫一次 progress/ 目录 + 跑一次全量闸门即可。

---

## 六、文件域（长期不变，这是路线图的骨架）

| 席位 | 独占域 | 绝不触碰 |
|---|---|---|
| 席1 | `src/host/kernel/**`（新建文件）、`tests/desktop/kernel-*.test.ts` | engine 层、tools、package.json |
| 席2 | `src/host/engine/**`、`tests/desktop/web-engine-*.test.ts`、`tests/desktop/engine-*.test.ts` | kernel 层、tools、package.json、agent-loop.ts |
| 席3 | `tools/**`、`tests/desktop/tools-*.test.ts`、`tests/desktop/metrics-*.test.ts`、`package.json` | src 下任何 .ts |

**跨域需求 = 写进自己进度文件的「遗留」，由 PM 决定派给谁。不要自己去改别人的文件。**

---

## 七、停手条件（只有这四条，触发才停）

1. 阶段验收命令跑不过，且 30 分钟定位不到
2. 发现必须改别人文件域才能继续（写清需要什么，停手）
3. 发现路线图里某阶段的技术前提是错的（立刻停手，说明）
4. 某阶段超出预估 2 倍工时

**除此之外一律继续跑。**

---

## 八、并发安全（三席同时改代码的唯一纪律）

- 只写自己独占域
- 每次落盘前跑一次 `git status --porcelain` 自检，确认没碰别人文件
- 不许 `git commit` / 切分支 / `git stash`
- package.json 只有席3 能改，且每次只加一行

---

## 九、与旧制度的关系

- `goals/` 目录作废，保留归档不删
- `handoff/` 目录保留（放 progress 的旧格式，不再新增）
- STATE.md 仍是项目级唯一真相，但只记「谁跑到哪个阶段」
